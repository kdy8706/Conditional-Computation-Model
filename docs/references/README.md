# References and design notes

This folder keeps the materials used to document the scientific motivation and model design of the conditional computation model.

## Included files

- [Kim et al. (2026)](Kim%20et%20al.%2C%202026.pdf), *A Wobbling Ratio for diagnosing phase evolution of the Ulleung Warm Eddy from its three-dimensional tilt structure*. Frontiers in Marine Science, 13, 1860054. https://doi.org/10.3389/fmars.2026.1860054
- [ocean_3D_temperature_conservation_equation.txt](ocean_3D_temperature_conservation_equation.txt), a design note on the three-dimensional ocean temperature conservation equation and vertical heat transport.
- [Liu et al. (2024)](liu%20et%20al.%2C%202024%20%2B%20tilting.pdf), *Reconstructing 3-D Thermohaline Structures for Mesoscale Eddies Using Satellite Observations and Deep Learning*. IEEE Transactions on Geoscience and Remote Sensing, 62. https://doi.org/10.1109/TGRS.2024.3373605
- [Yu et al. (2022)](yu%20et%20al.%2C%202022%20%2B%20tide.pdf), *An offshore subsurface thermal structure inversion method by coupling ensemble learning and tide model for the South Yellow Sea*. Frontiers in Marine Science, 9, 1075938. https://doi.org/10.3389/fmars.2022.1075938
